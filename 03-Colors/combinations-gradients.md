# Combinações Permitidas, Gradiente e Cores Proibidas

## Combinações aprovadas

| Fundo | Texto/elemento | Uso típico |
|---|---|---|
| Creme | Dark | Corpo de texto padrão, qualquer peça |
| Dark | Creme | Cards escuros, footer, header de comunicado |
| Verde | Dark | Badges, pills, CTAs pequenos |
| Creme | Verde (apenas elemento gráfico/ícone, não texto corrido) | Headlines com 1-2 palavras de destaque, ícones |
| Dark | Verde (stroke/ícone) | Detalhes gráficos sobre cards escuros |

## Gradiente oficial

Não há, até o momento, um gradiente oficial validado pela skill da marca. **Se uma peça pedir gradiente, prefira evitar** ou usar uma transição sutil entre Verde dark (`#6A9F4A`) e Verde (`#8EC36D`) apenas em elementos decorativos pequenos (nunca em fundo de texto). Validar com o Matheus antes de oficializar um gradiente como padrão.

## Cores proibidas

| ❌ Nunca usar | Por quê |
|---|---|
| Branco puro (`#FFFFFF`) como fundo principal | Quebra a identidade — o fundo padrão é Creme |
| Preto puro (`#000000`) como texto/fundo | A marca usa Dark (`#1C2621`), não preto neutro |
| Qualquer verde fora da paleta (ex.: verde-bandeira saturado, verde neon) | Foge da identidade visual estabelecida |
| Cores aleatórias "de apoio" não documentadas aqui | Toda cor nova precisa ser validada e adicionada a este arquivo antes do uso |

> Excepcionalmente, ilustrações de serviço podem usar uma **cor utilitária pontual** fora da paleta (ex.: amarelo do descarpack de perfuro-cortantes) — ver [`../08-Illustrations`](../08-Illustrations). Isso não é uma cor de marca, é um código de cor real do equipamento sendo ilustrado.
