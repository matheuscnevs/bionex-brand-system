### Erros que viraram regra (histórico real, da skill oficial)

1. **v1**: fontes erradas/cores genéricas → paleta fixa + DM Sans.
2. **v2**: logo recriada em SVG → sempre usar PNG oficial.
3. **v3**: HTML como entrega final → sempre PPTX editável.
4. **v4-v5**: formas chanfradas ignoradas → shape SVG inline obrigatório.
5. **v6**: arte comercial tratada como documento → mentalidade de social media.
6. **v6**: fato errado ("24h") + 3 textos competindo + decoração gratuita + sem imagem → validação de fatos + 1 elemento por container + ilustração obrigatória + sem decoração gratuita.
