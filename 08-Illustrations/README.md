# 08 · Illustrations

## Estilo

- **Outline + cores chapadas** (flat colors) — nunca fotorrealismo nem gradientes complexos.
- Espessura de linha consistente (média, não ultrafina) em toda a peça.
- Cores: paleta oficial (`../03-Colors`) + uma única cor utilitária pontual quando o objeto real exigir (ex.: amarelo do descarpack).

## Ilustrações por serviço (referência oficial da skill)

| Serviço | Visual reconhecível |
|---|---|
| Resíduos infectantes | Descarpack amarelo + saco leitoso + símbolo de biohazard |
| Dedetização | Spray verde + EPI/luvas verdes |
| Sanitização | Pulverizador + gotas + bactéria/germe estilizado |
| Caixas d'água | Caixa azul + gota |
| Fossa / desentupimento | Camião-tanque + tubulação |
| Resíduos comuns | Lixeira + setas de reciclagem |
| Consultoria ambiental | Folha + checklist + escudo |

## Regra de reconhecimento

A ilustração precisa ser **identificável pelo público-alvo em menos de 1 segundo**, sem precisar de legenda. Se a ilustração exigir explicação para entender o que é, ela falhou.

## Uso

- Sempre que não houver foto real disponível (ver `../07-Photography`).
- Como elemento de apoio na coluna direita de artes comerciais (ver `../19-AI-Guidelines`).
- **Nunca** para recriar a logo — isso é proibido em qualquer contexto (ver `../02-Identity/logo.md`).
