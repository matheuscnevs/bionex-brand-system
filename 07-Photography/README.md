# 07 · Photography

## A fórmula visual da Bionex deve transmitir

| Conceito | Como aparece em foto |
|---|---|
| Tecnologia | Equipamentos modernos de aplicação/sanitização, EPIs completos |
| Sustentabilidade | Contraste entre vegetação amazônica e a intervenção técnica controlada |
| Controle de Pragas | Profissional aplicando produto com equipamento certo (nunca aerossol doméstico genérico) |
| Meio Ambiente | Natureza amazônica real — rio, mata, não paisagem genérica de banco de imagens |
| Sanitização | Processo visivelmente técnico (pulverização, EPI, sinalização de área) |
| Profissionais em campo | Pessoas reais da equipe, uniformizadas, em ação — nunca modelo de banco de imagens posando |
| Equipamentos modernos | Foco nítido no equipamento, sem aparentar improviso |
| Natureza / Amazônia | Reforça o contexto regional real da empresa |
| Segurança | EPI completo e visível sempre que a foto mostrar aplicação de produto |
| Confiabilidade | Cenas de processo organizado (antes/durante/depois), nunca cauótico |

## O que NÃO usar

| ❌ Evitar | Por quê |
|---|---|
| Banco de imagens genérico (modelo sorrindo sem contexto, escritório corporativo genérico) | Não representa a operação real de campo da Bionex |
| Imagens de pragas/insetos em close extremo e chocante | Tom alarmista — contraria o tom "técnico, não alarmista" (ver `../01-Brand/personality.md`) |
| Profissional sem EPI aplicando produto | Transmite o oposto de segurança/confiabilidade |
| Paisagem amazônica estética sem nenhuma relação com o serviço | Decorativo, não reforça a mensagem |
| Filtro/edição pesada que distorça as cores reais (verde/creme da marca) | Quebra a consistência da paleta oficial |

## Quando não houver foto real disponível

Use ilustração SVG conforme [`../08-Illustrations`](../08-Illustrations) — nunca gere uma "foto" sintética via IA tentando passar por fotografia real da equipe/cliente.
