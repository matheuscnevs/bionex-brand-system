# 06 · Layouts

Padrões de estrutura de página. Componentes individuais em [`../05-Components`](../05-Components).

## Landing Page

1. Hero (headline curta + CTA + imagem/ilustração do serviço)
2. Prova social discreta (licenças, não depoimentos fabricados)
3. Seção de serviços (cards)
4. Como funciona / processo (timeline)
5. CTA final (card Dark chanfrado, telefone/WhatsApp em destaque)
6. Footer

## Institucional ("Sobre")

1. Hero com posicionamento (ver `../01-Brand/positioning.md` — ainda rascunho)
2. História real da empresa (ver `../01-Brand/brand-story.md` — pendente de informações reais)
3. Licenças e área de atuação
4. Equipe (se houver material aprovado)
5. CTA final

## Blog

- Listagem em grid 2-3 colunas, card com imagem + título Dark + data em Cinza.
- Página de artigo: largura de leitura confortável (≈65-75 caracteres por linha), tipografia conforme `../04-Typography`.

## Página de Serviço

1. Hero específico do serviço (ilustração reconhecível — ver `../08-Illustrations`)
2. O que está incluíso (lista real, confirmada com o Matheus — ver `../13-Commercial`)
3. Como funciona o agendamento
4. Licenças aplicáveis a esse serviço
5. CTA

## Página Comercial (proposta/orçamento online)

- Estrutura tipo documento (ver `../18-Documents`), não estrutura de arte comercial — carga informacional alta é esperada aqui.

## Dashboard

- Fundo Creme, cards Dark para métricas-chave, Verde reservado a indicadores positivos/concluidos.
- Tabelas seguem `../05-Components#tables`.

## Aplicativo

- Navbar inferior (mobile) com ícones conforme `../09-Icons`.
- Botão de ação principal (ex.: "Agendar visita") sempre fixo/visível.
