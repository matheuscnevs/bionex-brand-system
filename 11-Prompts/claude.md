# Prompts — Claude / Claude Design

## Prompt-base de contexto (cole antes de pedir qualquer peça)

```
Você vai produzir material para a Bionex Soluções Ambientais. Siga estritamente:

- Paleta: Verde #8EC36D, Verde stroke #7AB55A, Verde dark #6A9F4A,
  Creme #F2F2EA (fundo padrão, nunca branco puro), Dark #1C2621 (texto
  principal), Cinza #5E5E5E (texto secundário).
- Fonte única: DM Sans.
- Forma característica: cantos chanfrados (não arredondados) em cards/blocos.
- Logo: nunca recriar em SVG. Usar arquivo PNG oficial (4 versões conforme fundo).
- Nunca afirmar atendimento 24h/emergência a menos que eu confirme.
- Antes de citar qualquer número, prazo ou regulamentação sobre o serviço, pergunte-me para validar.
- Se for arte comercial (redes sociais): tipografia como herói, 1 elemento
  dominante por card, logo discreta no canto inferior, sem moldura.
- Se for comunicado/documento: estrutura header→corpo→footer, mais
  formal e informativo.
```

## Prompt — arte comercial para Instagram

```
Crie uma arte comercial quadrada (1080x1080) para Instagram sobre [SERVIÇO],
seguindo o contexto Bionex acima. Estrutura: pré-header pequeno → coluna
esquerda com headline curta (2 palavras hero) → coluna direita com
ilustração SVG reconhecível do serviço → card CTA dark chanfrado com
WhatsApp em destaque → logo discreta + redes sociais no rodapé.
```

## Prompt — comunicado oficial (A4)

```
Crie um comunicado A4 retrato sobre [ASSUNTO], seguindo o contexto Bionex
acima. Estrutura: header dark com logo creme → stripe verde → banner de
atenção se for aviso → corpo creme com cards informativos → footer dark
com selos de licença (DEVISA, FVS, IPAAM, IBAMA) em linha discreta.
```
