# Prompts — ChatGPT / GPT Image

## Para copy (ChatGPT)

```
Escreva [tipo de texto] para a Bionex Soluções Ambientais sobre [assunto].
Tom de voz: direto, técnico quando necessário, honesto sobre prazos (nunca
prometa "24h" ou "emergência" a menos que eu confirme que é real). Use
frases curtas. Evite jargão de marketing genérico ("inovador",
"disruptivo"). Pergunte-me antes de citar qualquer número, prazo ou
regulamentação específica que você não tenha certeza.
```

## Para imagem de apoio (GPT Image)

```
Fotografia/ilustração de apoio para Bionex Solução Ambiental, sobre
[serviço]. Estilo: outline + cores chapadas se for ilustração; se for
foto, estilo documentário realista (profissional uniformizado, EPI
completo, equipamento moderno, contexto amazônico real) — nunca banco de
imagens corporativo genérico. Paleta de apoio: verde #8EC36D, creme
#F2F2EA, dark #1C2621. NÃO inclua nenhum logotipo ou texto na imagem —
a marca é aplicada depois, separadamente.
```

> ⚠️ GPT Image não deve gerar a logo da Bionex sob nenhuma circunstância — mesmo pedindo "recrie a logo", isso produz uma versão inconsistente com o arquivo oficial.
