## Favicon / ícone de app (confirmado no manual de identidade visual)

Para favicon e ícone de aplicativo, o contêiner é um **quadrado com cantos arredondados padrão do sistema** (não chanfrado) com apenas o símbolo "B" em Verde, sem o wordmark. Isso é uma exceção à regra geral de "cantos chanfrados" — nesses contextos específicos (favicon, ícone de app), siga a convenção de plataforma (iOS/Android/navegador), não a forma de marca.
