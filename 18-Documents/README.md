# 18 · Documents (Comunicados Oficiais)

Padrão para comunicados informativos (avisos a clientes/moradores, notificações de regras) — diferente de arte comercial. Ver distinção completa em [`../19-AI-Guidelines`](../19-AI-Guidelines).

## Estrutura — A4 retrato (8.27"×11.69")

1. **Header** dark com logo creme (`logo_green_cream.png`)
2. **Stripe verde** (faixa fina decorativa)
3. **Banner ATENÇÃO** (se for um aviso) — fundo de destaque, texto direto
4. **Corpo** creme com cards informativos (um assunto por card)
5. **Footer** dark com selos de licença (DEVISA · FVS · IPAAM · IBAMA) em linha discreta + contatos oficiais

## Diferença de mentalidade vs. arte comercial

| Comunicado | Arte comercial |
|---|---|
| Estrutura tipo Word: header → corpo → footer | Hook visual em 1 segundo |
| Carga informacional alta (pode ter vários parágrafos/cards) | Tipografia como herói, 1-2 palavras grandes |
| Moldura/selo/header grande são aceitáveis | Moldura e header grande viram "poluição visual" |
